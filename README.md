# Projeto HTML Modular com Editor e Integração ao Supabase

## Visão Geral
Este projeto visa criar um editor HTML modular com pré-visualização ao vivo, suporte a organização de pastas e arquivos, e funcionalidades para importar/exportar projetos em formato ZIP. O sistema será integrado ao Supabase para armazenamento de códigos HTML e funcionalidades de chat. O editor será responsivo, adaptando-se a dispositivos móveis e desktops.

## Funcionalidades Principais
1. **Editor HTML**:
   - Edição de código HTML em tempo real.
   - Pré-visualização ao vivo das alterações.
   - Suporte a múltiplos arquivos e pastas.

2. **Gerenciamento de Arquivos**:
   - Criar, renomear e duplicar arquivos/pastas.
   - Importar e exportar projetos em formato ZIP.
   - Organização hierárquica de pastas e subpastas.

3. **Integração com Supabase**:
   - Armazenar e recuperar códigos HTML do banco de dados.
   - Funcionalidade de chat para colaboração.

4. **Responsividade**:
   - Suporte a visualizações em modo retrato e paisagem em dispositivos móveis e desktops.
